7e. How weapons work in combat (new)

Craft → inventory (non-stackable, qty 1) → equip to mainHand via equipItem (convex/items.ts:752). One weapon at a time; equipping swaps the old one back to inventory. Only equipped gear counts: getEquippedStatBonuses (convex/items.ts:74) sums each equipped piece's effectAmount plus its applied augments.

Weapon base damage & attack speed (new)

Each weapon gets data-driven baseDamage + attackSpeed (attacks/s) on its item record. Damage triangle: mace high, sword mid, dagger low; speed inverts it (dagger fast, sword mid, mace slow) so baseline DPS is comparable and the choice is feel + stat scaling, not a solved optimum. Stat bonuses apply on top:

Each weapon declares damageStat (new item field: str | dex | int). Bows are dex weapons, staves int weapons — int now feeds attack for the first time (previously defense/HP only). Baselines stay within ≈10% of each other so the choice is build identity (which stat you stack) and feel (fast/light vs slow/heavy), not a solved optimum.

New formulas (coefficients become gameBalance keys with the current values as fallbacks): attack = weapon.baseDamage + scalingStat×1.2, where scalingStat is the weapon's damageStat; speed = max(0.5, weapon.attackSpeed + max(0, dex−10)×0.1 − Σ armor speedPenalty). Additive speed keeps weapon ordering stable at any dex; the 0.5 floor stops full heavy plate from rooting the player. Shared helper (e.g. in convex/items.ts) feeds both simulateRegularBattle (convex/combat.ts:148) and the manual-attack cooldown (convex/players.ts:234).

All tuning stays in domain records + balance keys per AGENTS.md.
